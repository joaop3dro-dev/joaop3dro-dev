## 🧱 Engineering Philosophy

I prefer systems that are:
- simple before being sophisticated
- structured before being fast to build
- maintainable before being impressive

I value clear separation of concerns, predictable APIs, and pragmatic architectural decisions (MVC when appropriate, clean layering when necessary).

Complexity is only acceptable when it solves a real problem, not when it exists for aesthetic reasons.
