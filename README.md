## About

I am a full-stack developer focused on building reliable web applications, from backend business logic and REST APIs to responsive frontend interfaces.

My work combines Python and Django for backend development with React and Next.js for frontend applications. I also work with relational databases, caching, containerization, and cloud deployment.

I value clear domain boundaries, consistent data handling, explicit permissions, automated testing, and pragmatic architecture.

> Clear business rules. Explicit data integrity. Accessible interfaces. Complexity only when required.

## Engineering Approach

```text
Understand the requirement
        ↓
Define responsibilities and data flows
        ↓
Implement business rules and interfaces
        ↓
Validate critical behavior with tests
        ↓
Prepare the application for deployment
```

I aim to keep business rules centralized, responsibilities clearly separated, and important state changes protected through validation and database transactions.

On the frontend, I prioritize responsive behavior, accessibility, clear visual hierarchy, and maintainable components.
